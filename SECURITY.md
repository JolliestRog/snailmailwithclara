# Security policy

Please report vulnerabilities privately through GitHub's private vulnerability reporting feature. Do not include real postal addresses, recovery codes, passkey responses, invitation tokens, or other members' personal information in a report.

Supported versions are the commit currently deployed at `snailmailwithclara.facey.page` and the latest commit on the repository's protected `main` branch.

For a credible exposure, operators should stop invitations and deployments, preserve body-free audit metadata, revoke affected credentials, and follow `THREAT_MODEL.md`. Never ask a member to send their recovery code for troubleshooting.
